Boas-vindas ao meu novo blog!

Por: Matheus Kassen Sarrao Francisco

Aqui vou compartilhar dicas de programação e curiosidades da área de tecnologia. A proposta é aprender como as páginas da internet funcionam e usar esse conhecimento para criar projetos úteis e inclusivos.

Toda página começa com uma estrutura HTML. O conteúdo visível fica no <body>, enquanto informações importantes para o navegador ficam no <head>. Com CSS, podemos definir cores, contraste, largura e espaçamentos para melhorar a leitura.

Dica de acessibilidade Imagens devem ter um texto alternativo claro, e texto e fundo precisam ter contraste suficiente para uma leitura confortável.

A origem do Bluetooth
Uma homenagem à história viking

Por: Matheus Kassen Sarrao Francisco

O nome Bluetooth foi inspirado no rei dinamarquês Harald “Bluetooth” Gormsson. Assim como ele ficou conhecido por unir povos, a tecnologia foi criada para conectar diferentes dispositivos sem o uso de cabos.

Fonte: Bluetooth SIG
